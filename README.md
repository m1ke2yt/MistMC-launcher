# Mist MC Launcher

Официальный лаунчер сервера **mistmc.gg**. Minecraft **1.21.11** (версия сервера) и новее —
**26.1–26.3** на выбор, вход по нику или через
аккаунт **Microsoft** (официальное окно входа в браузере), сборки **Fabric / Forge / Vanilla**,
встроенный каталог модов/ресурспаков/шейдеров с Modrinth, автообновление.

**Это полные исходники актуальной версии** — публикуем их, чтобы любой мог убедиться,
что лаунчер делает ровно то, что заявлено, и собрать его самостоятельно.

Не входят в публикацию только данные официальной сборки — они лежат в одном файле
`src/build-secret.js`, и в репозитории он заглушка с пустыми значениями:

- Azure `client_id` для входа Microsoft (подставьте свой из Azure/Entra ID);
- ключ подписи запросов к сайту;
- служебные адреса: зеркала, прокси и пути API сайта Mist MC.

Собранный из исходников лаунчер ставит и запускает игру, работает с Modrinth и
Mojang напрямую, а к сайту Mist MC не обращается (косметика, свой скин, оценки
модов и хартбит выключены). Логика при этом видна целиком — скрытого кода нет:
видно, что именно и когда лаунчер отправляет, не видно только куда.

Лицензия: source-available (см. `LICENSE`) — код открыт для чтения и проверки,
но распространять сборки и выдавать их за официальный лаунчер Mist MC запрещено.

## Что лаунчер делает

- скачивает клиент, библиотеки, ассеты Mojang и загрузчик модов (Fabric/Forge,
  в своих сборках с 1.8.16 — ещё NeoForge и Quilt);
- для Minecraft 26.x один раз скачивает у Mojang Java 25 в свою папку настроек
  (в лаунчер вшита Java 21, этим версиям её мало), для версий до 1.17 — Java 8
  или 16 оттуда же — `src/versions.js`;
- с 1.8.16 ведёт **сборки**, как инстансы в Prism Launcher: у каждой своя папка
  (`<папка игры>/instances/<название>`), версия Minecraft, загрузчик, память, моды,
  миры и время в игре; библиотеки и ассеты у всех сборок общие (`src/profiles.js`).
  Главная сборка «Mist MC» — прежняя папка игры с модами сервера. Удаление сборки
  убирает её папку только в корзину Windows и только если она лежит в папке
  `instances`;
- с 1.8.16 по вашей кнопке **переносит сборки из Prism Launcher** (и MultiMC/PolyMC —
  у них тот же формат), `src/prism.js`: ищет папку Prism в стандартных местах
  (`%APPDATA%\PrismLauncher`, Scoop) или берёт указанную вами, читает
  `prismlauncher.cfg`, `instance.cfg`, `mmc-pack.json`, `instgroups.json` и значки
  и копирует папку игры каждого выбранного инстанса — моды, миры, настройки, паки.
  Prism при этом не меняется. Не копируются журналы, крэш-отчёты, кэши и моды,
  запрещённые на Mist MC (читы, X-Ray, JourneyMap) — их список показывается после
  переноса. Из `accounts.json` берутся только ники офлайн-аккаунтов, если вы
  отметили этот пункт; токены Microsoft лаунчер не использует и никуда не передаёт;
- чтобы показать перенесённые или положенные в папку вручную моды с названием и
  значком, отправляет в Modrinth sha1 этих файлов (тот же запрос, что делают Prism
  и другие лаунчеры; `adoptContent` в `src/mods.js`);
- ставит моды только из каталога Modrinth (с блоклистом читерского — X-Ray и
  подобное не ищется и не ставится);
- с 1.8.9 берёт список рекомендованных модов, шейдеров и паков с сайта Mist MC
  (только названия проектов Modrinth и описания, без данных игрока; `loadCurated`
  в `src/mods.js`), чтобы подборку можно было менять без нового релиза; сайт
  недоступен — показывает встроенный список;
- сверяет моды в папке игры между собой и с выбранной версией игры: читает
  `fabric.mod.json` и классы джарников локально, предупреждает о конфликтах и
  подбирает совместимые версии с Modrinth (`src/mods.js`);
- перед запуском на версии, отличной от серверной, спрашивает сервер обычным
  статус-пингом, примет ли он её (`serverAccepts` в `src/versions.js`);
- синхронизирует серверный ресурспак по sha1 (`src/respack.js`);
- если Modrinth напрямую не отвечает (у части провайдеров он режется), запросы к
  каталогу и скачивание модов идут через прокси Mist MC — тогда прокси видит, какие
  моды вы ищете и качаете (`robustFetch` в `src/mods.js`; в сборке из исходников
  прокси нет);
- переносит настройки/миры/паки из других лаунчеров по явной команде пользователя
  (`src/migrate.js`) — с бэкапами, ничего не удаляя;
- показывает статус в Discord (Rich Presence, отключается в настройках);
- при запуске игры отправляет на сайт ник для внутриигровых бонусов
  (`sendLauncherHeartbeat` в `src/main.js` — можете убедиться, что больше ничего);
  запрос подписывается HMAC-ключом официальной сборки, чтобы его нельзя было
  просто подделать от имени лаунчера.
- в сборку Fabric вшит мод **MistSocial** (с 1.7.11): друзья, личные сообщения
  в меню Esc и свой мир для друзей с белым списком. Мод подключается к сервису
  Mist MC по TLS с закреплённым сертификатом. Для входа
  вы один раз вводите в игре пароль от аккаунта mistmc.gg — его проверяет сайт,
  мод хранит только токен сессии (`config/mistsocial/session.json`); премиум-аккаунт
  подтверждается через Mojang без передачи токена. Переписка хранится на сервере
  Mist MC; **если вы или собеседник в этот момент играете на сервере Mist MC,
  сообщение попадает в журнал модерации** — так же, как обычные ЛС на сервере.
  В мир пускаются только отмеченные хозяином друзья. С 1.7.12 игра сначала
  пробует **прямое соединение между игроками** (UDP с пробивкой NAT и, если
  роутер умеет, пробросом порта по UPnP на время игры; трафик шифруется
  AES-GCM ключом, который сервис выдаёт только двум участникам). При прямом
  соединении ваш IP-адрес виден другу — как в любой P2P-игре. Не получилось
  за ~6 секунд — игра идёт через ретранслятор Mist MC. С 1.8.4 мод перед входом
  в мир друга **сверяет моды**: открывая мир, хозяин сообщает сервису список
  своих модов, нужных гостю (id, название, версия и sha1 файла; чисто клиентские
  моды не передаются), и получить его могут только приглашённые друзья. Если
  у вас чего-то не хватает, игра покажет список, и по вашей кнопке лаунчер
  скачает эти моды с Modrinth (той же версии, что у друга; адресов для
  скачивания от друга он не принимает) и перезапустит игру. Для этого лаунчер
  слушает порт на 127.0.0.1 с одноразовым ключом, который получает только
  запущенная им игра (`src/friendsync.js`). С 1.8.5, если у друга другая
  версия игры, по вашей кнопке лаунчер перезапустит игру на его версии.
  Мод можно выключить во вкладке «Моды».
- в сборку Fabric вшит мод **MistTrimGlow** (с 1.8.2): светящаяся отделка брони и
  элитр Mist MC не темнеет в темноте и светится под шейдерпаками. Мод только меняет
  отрисовку отделки, помеченной сервером, в сеть ничего не отправляет и на других
  серверах ничего не делает. Его тоже можно выключить во вкладке «Моды».
- в сборку Fabric вшиты мод **Customizable Player Models** (с 1.8.5; автор tom5454,
  лицензия MIT, файл без изменений) и небольшой мод **MistCpmEmotes**. На Mist MC
  игроки носят 3D-модели вместо скина, и эти моды их показывают; какую модель видно
  у игрока, решает сервер. MistCpmEmotes чинит эмоции Emotecraft на таких моделях
  (включая сгибы рук и ног), с 1.8.6 показывает и сгибы, записанные в самой модели,
  с 1.8.8 — тазобедренный сустав (нога не отрывается от тела у моделей, где он
  размечен), и в сеть ничего не отправляет. На других серверах
  Customizable Player Models работает как обычно. Оба мода можно выключить
  во вкладке «Моды».
- с 1.8.10 там же мод **MistCpmSmooth** — плавность анимаций моделей CPM: при смене
  позы (стоит → идёт → бежит) детали доводятся до новой позы за долю секунды, а не
  прыгают; зацикленные анимации не дёргаются на стыке цикла; ходьба и бег идут в темпе
  настоящей скорости игрока; у моделей с размеченным хвостом — инерция хвоста. Работает
  только у вас в игре (как вы видите чужие модели), на любом сервере, в сеть ничего
  не отправляет; выключается во вкладке «Моды». С 1.8.12 (мод 1.0.1) смена позы идёт
  по плавной кривой за 0,4 с: деталь мягко трогается, не останавливая своё движение,
  быстро проходит середину и мягко встаёт в новую позу.
- с 1.8.11 в сборке есть необязательный мод **MistWave** — Яндекс Музыка в игре
  («Моя волна», лайки, тексты песен, плеер и оформление). **По умолчанию он
  выключен** и ничего не делает, пока вы сами не включите его во вкладке «Моды»
  (с 1.8.14 — включён, без входа в Яндекс ничего не показывает).
  Включённый мод связывается только с Яндекс Музыкой (вход по коду на странице
  Яндекса; токен хранится у вас в `config/mistwave.json` и никуда больше не
  уходит) и, чтобы найти текст песни, отправляет название трека, исполнителя и
  длительность в открытые базы текстов LRCLIB и NetEase. Музыка играет только у вас.
  С 1.8.13 (мод 1.1.0): если у вас на сервере Mist MC есть питомец-колонка, мод
  сообщает серверу, какой трек у вас играет (номер трека в Яндекс Музыке, название,
  исполнители, позиция) и ваши настройки вида сцены. Сервер пересылает это игрокам
  рядом с модом, и они включают тот же трек со своего входа в Яндекс. Звук через
  сервер не идёт. Выключается во вкладке «Вид» плеера: «Колонка играет мою музыку».
  Чужие колонки можно заглушить или скрыть там же.
- с 1.8.14 моды сборки обновляются без новой версии лаунчера: при старте и перед
  запуском игры лаунчер скачивает с сайта список `mods/manifest.json` (имя файла,
  sha256, размер) и докачивает недостающие джарники в свою папку
  (`bundled-mods` в данных лаунчера). Файл берётся, только если sha256 совпал со
  списком; нет сети или файл не сошёлся — играете с прежним набором или с модами,
  вшитыми в exe (`src/remotemods.js`). С 1.8.15 открытый лаунчер сверяется со
  списком сам раз в 5 минут и при открытии вкладки «Моды» — перезапускать его не нужно. Выключенный вами мод сборки остаётся
  выключенным и после его обновления. MistWave с 1.8.14 включён по умолчанию,
  выключается во вкладке «Моды».

## Чего лаунчер НЕ делает

- **не видит ваш пароль Microsoft** — вход идёт через официальную страницу
  login.microsoftonline.com (OAuth + PKCE, код в `src/msauth.js`), лаунчер получает
  только игровой токен;
- не читает файлы за пределами своей папки игры (кроме переноса из другого
  лаунчера — по вашей явной команде; кроме того, при старте лаунчер смотрит,
  есть ли на компьютере Prism и сколько в нём сборок, чтобы предложить перенос, —
  читает его описания сборок и `accounts.json` и ничего не копирует и не отправляет);
- не устанавливает ничего, кроме файлов игры;
- не отправляет никакой телеметрии, кроме ника при запуске игры и статуса
  «в меню / в одиночной / в сетевой игре» для ваших друзей в MistSocial (см. выше).

## Собрать самому

```
npm ci
node scripts/fetch-jre.mjs win     # или linux — скачает JRE 21 (Temurin) в resources/
npm start                          # запуск в dev-режиме
powershell -File .\build.ps1       # полная сборка установщика (Windows)
```

## Проверить скачанный файл

Официальная раздача: https://mistmc.gg/downloads/

- контрольная сумма релиза публикуется в `https://mistmc.gg/downloads/latest.yml`
  (поле `sha512`, base64) — сверьте с вашим файлом:
  `certutil -hashfile MistMC-Launcher-win-x64.exe SHA512`;
- отчёт VirusTotal доступен по хэшу файла;
- автообновление качает новые версии только с mistmc.gg по HTTPS и проверяет их
  sha512 перед установкой (electron-updater).

Установщик пока не подписан сертификатом — SmartScreen может показать предупреждение
«неизвестный издатель». Работаем над подписью; до тех пор — исходники и хэши выше.

## Стек

- Electron, `@xmcl/core` + `@xmcl/installer` (установка и запуск игры),
  `electron-updater` (автообновление), `@xhayper/discord-rpc` (Discord-статус).
- Offline-UUID считается как на сервере: name-based UUID от `OfflinePlayer:<ник>`.

Вопросы и жалобы: тикет на https://mistmc.gg или Discord сервера.
